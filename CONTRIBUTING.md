# Contributing

Use Node.js 20 or newer.

```sh
npm install
npm test
npm run check
npm run smoke
```

Keep scanner behavior deterministic, preserve zero runtime dependencies, and update README or changelog entries when CLI behavior changes. Add tests for changes to scoring, parsing, comparison, or renderers. Keep generated demo files aligned with the current local CLI output.

Open an issue before large behavior changes. Small focused pull requests are easiest to review.
